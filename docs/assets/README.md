# FMD Italia — Brand Assets

Logo della campagna **FMD Italia**, costruito sul motivo della **«collana di perle»**
(*string of beads*), il segno radiologico distintivo della Displasia Fibromuscolare.

## File

| File | Uso |
|---|---|
| `fmd-italia-logo.svg` | Logo orizzontale, **sfondo chiaro** (testo convertito in tracciati: identico ovunque) |
| `fmd-italia-logo-inverse.svg` | Logo orizzontale, **sfondo scuro** |
| `fmd-italia-mark.svg` | Solo simbolo (per favicon, avatar, spazi ridotti) |
| `png/fmd-italia-logo-light-1600.png` | Logo chiaro, raster 1600px (trasparente) |
| `png/fmd-italia-logo-inverse-1600.png` | Logo scuro, raster 1600px (trasparente) |
| `png/fmd-italia-mark-512.png` · `-1024.png` | Simbolo raster (trasparente) |
| `png/fmd-italia-avatar-1080.png` | Avatar social quadrato 1080×1080 (simbolo su teal) |
| `png/og-share-light-1200x630.png` · `-dark` | Immagine di anteprima per la condivisione (Open Graph) |
| `png/favicon-180.png` · `favicon-32.png` | Icona per browser / dispositivi |

## Colori

- **Teal** primario `#0e6b74` (scuro `#0a555d`)
- **Terracotta** accento `#cf6a55` (la «perla» del simbolo)
- **Inchiostro** `#17282b` · **Grigio** `#5c6b6d`

## Regole d'uso

- Mantieni un'area di rispetto attorno al logo pari almeno all'altezza del simbolo.
- Non deformare, non ruotare, non alterare i colori del logo.
- Usa la versione **inverse** su sfondi scuri o fotografici scuri.
- Le versioni SVG hanno il testo **convertito in tracciati**: si vedono identiche su
  qualsiasi dispositivo, anche senza i font installati.

*Il simbolo richiama un segno clinico ma non è materiale medico né diagnostico.*
